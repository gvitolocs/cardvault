# Production root landing

`https://pokoin.com/` is a static page, not Flutter `LandingScreen`.

**Full pipeline and every file:** `/home/nez/Projects/pokoin-web/docs/LANDING.md`

## This repo’s files in that pipeline

| Path | Do |
| --- | --- |
| `web/home.html` + `web/home/` | Generated by `pokoin-web/scripts/sync-landing.sh`. Do not hand-edit. |
| `web/index.html` | Flutter shell. Never replace with the landing. |
| `vercel.json` | `/` rewrite → `/home.html`; catchall → `/app.html`; `/home/:path*` cached 1h. |
| `deploy-pokoin-web.sh` | Flutter build, copy landing onto `index.html`, Flutter shell onto `app.html`, Vercel prod. |
| `scripts/landing-root.test.js` | Rewrite order + copy assertions. |
| `scripts/verify-production-aliases.js` | Prod checks. Explorer `/` is Caddy, not marketplace JSON. |
| `lib/utils/public_home.dart` | In-app Home punches out to static `/`. |
| `lib/utils/browser_location_web.dart` | `location.assign('/')`. |
| `lib/screens/landing_screen.dart` | Still compiled for `flutter run` / SPA `/`. Not what Vercel serves at `/`. |
